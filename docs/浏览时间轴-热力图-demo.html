开源情况

热力图是图表类型，画它的库基本都是开源的

「热力图（heatmap）」是一种标准图表类型，不是哪家的专有技术。能画它的开源库很多，你项目已经装了一个：

库协议说明
ECharts（项目在用 ✅）Apache-2.0Apache 基金会开源，免费商用。package.json 里 echarts ^6.1.0 已打进插件 bundle；热力图是内置 series（type:'heatmap'），不用新装任何东西。趋势折线图、停留排行、HsHeatmap 全是它画的。
cal-heatmapMIT专做 GitHub 式日历热力图的小库（~10KB），比 echarts 轻，但要多带一个依赖。
Chart.js + matrix 插件MIT热力图要靠第三方 matrix 插件拼，不如 echarts 内置省事。
D3 / ApexChartsISC / MIT都能画，但项目没必要再引第二套图表库。
GitHub 贡献格子—GitHub 那张 Contributions 热力图是它自家自绘的 DOM，没有公开库；echarts 的 calendar+heatmap 可以做到一样的效果（左边示例就是）。
Highcharts非开源商用要付费授权，不碰。

结论：要用就是 ECharts，零新依赖。按天停留（日历热力图）和星期×小时（已有 HsHeatmap）两张图它都能出；唯一要写的是把 view-timeline 数据聚合成「天→总停留秒」和「星期×小时→次数」两个数组。
