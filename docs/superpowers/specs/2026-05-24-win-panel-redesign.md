# 1688 协作悬浮面板 — 布局重构设计

## 概述

重构 1688 产品详情页的悬浮窗口（win 面板），将产品概览信息作为首屏核心，评论和标签拆分为独立子页面，新增数据分析页。整体采用紧凑布局，减少垂直空间占用。

## 整体布局框架

```
┌─ 拖拽标题栏 "1688 协作" ─────────┐  ← 显示扩展名称
├─ 产品概览区（左右布局，尽量矮）────┤
│ ┌────┐ 商品标题（一行省略）        │
│ │ □  │ 供应商名称（一行省略）      │
│ │缩略│ 👁 328次 [C][李][张][+2]  │
│ └────┘                           │
├─ Tab ───────────────────────────┤
│ [商品] [供应商] [分析]            │
├─ SubTab（根据Tab动态变化）───────┤
│ [评论] [标签] 或 [用户浏览量] [浏览记录] │
├─ 内容区（页面内容）───────────────┤
│                                   │
│                                   │
│                                   │
└───────────────────────────────────┘
```

### 各层级说明

| 层级 | 内容 | 说明 |
|------|------|------|
| 标题栏 | "1688 协作" | 可拖拽，点击最小化按钮缩小为圆点 |
| 概览区 | 左图右信息 | 正方形缩略图 + 标题/供应商/浏览次数/头像栈 |
| Tab | 商品/供应商/分析 | 主切换栏 |
| SubTab | 动态变化 | 商品Tab→[评论][标签]；供应商Tab→[评论][标签]；分析Tab→[用户浏览量][浏览记录] |

## 产品概览区

```
┌────────┬─────────────────────────┐
│        │  秋季新款男式PU皮衣      │  ← 商品标题，一行省略
│  □ 缩略│  石狮市莫菲亚服装厂      │  ← 供应商名称，一行省略
│  正方形 │  👁 328次               │  ← 浏览次数总计
│        │  [C][张][李][+2]        │  ← HsAvatarStack 组件
└────────┴─────────────────────────┘
```

- **缩略图**：正方形，宽高相等，从产品页面 DOM 获取
- **商品标题**：单行，超出 `text-overflow: ellipsis`
- **供应商名称**：单行，超出 `text-overflow: ellipsis`
- **浏览次数**：所有用户浏览次数总和，带眼睛图标
- **头像栈**：复用现有 HsAvatarStack 组件，显示浏览过的同事头像

### 交互规则

| 功能 | 行为 |
|------|------|
| 输入评论 | 底部输入框，点击发送或回车提交，自身头像在左侧 |
| 点赞 | 点击 👍 变实心 +1，再次点击取消，显示点赞总数 |
| 排序切换 | 点击 ⏱ 切换"最新" / "最早"，默认按时间倒序（最新在上） |
| 搜索用户 | 点击搜索框弹出复选下拉框，可选一个或多个用户筛选 |

### 搜索用户组件

```
┌─ 搜索用户 ──────────────────────┐
│ 🔍 输入用户名...                 │
│ ┌──────────────────────────────┐│
│ │ ☑ Conley (3条)               ││  ← 用户名 + 该用户评论数
│ │ ☐ 张三   (0条)               ││
│ │ ☑ 李四   (1条)               ││
│ │ ☐ Alex   (0条)               ││
│ └──────────────────────────────┘│
│ [    应用筛选    ]               │
└─────────────────────────────────┘
```

- 根据评论数据自动生成用户列表
- 多选，勾选后点击"应用筛选"只显示选中用户的评论
- 清空所有勾选或点"清除"回到全部

### 相对时间显示规则

| 实际时间差 | 显示 |
|-----------|------|
| < 1 分钟 | 刚刚 |
| < 1 小时 | X分钟前（如"23分钟前"） |
| < 24 小时 | X小时前（如"5小时前"） |
| < 7 天 | X天前（如"3天前"） |
| < 30 天 | X周前（如"2周前"） |
| ≥ 30 天 | 月/日（如"3/15"） |

```
│ [         创建新标签             ] │  ← 创建后加入"我的标签池"
└──────────────────────────────────┘
```

### 标签操作规则

| 操作 | 行为 |
|------|------|
| 鼠标悬停已添加标签 | 弹出操作浮层："团队可见"切换 + "从本商品移除" |
| 从本商品移除 | 标签从"已添加"区移除，回到"我的标签池" |
| 点击我标签池中的标签 | 立即添加到本商品的"已添加"区 |
| 右键点击自己的标签（注） | 弹出右键菜单：修改 / 删除（永久删除） |
| 创建新标签 | 输入名称 + 选择颜色 + 设可见性 → 加入"我的标签池" |
| 别人的标签 | 完全不可见 |

> 注：右键菜单中的"删除"是从用户的标签池中永久移除，与"从本商品移除"不同。右键菜单在"已添加到本商品的标签"和"我的标签池"中均可用。
