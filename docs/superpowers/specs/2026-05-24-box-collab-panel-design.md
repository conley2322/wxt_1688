# 1688 协作面板 — Box 组件设计文档

## 概述

在 1688 搜索列表页的每个产品卡片下方（box 区域），嵌入一个协作信息面板。团队成员可以浏览产品、添加标签和评论，消除信息差，避免重复工作。

## 布局结构

```
┌─────────────────────────────────────────────────────────────┐
│ [🏷 3] [💬 2] [👁 12]              [C] [李] [张] [王] [+1] │  ← 固定顶栏
├─────────────────────────────────────────────────────────────┤
│                                                              │
│  ┌───────── 滑动内容区（2面板，200%宽） ──────────────────┐  │
│  │ 面板 0：标签  |  面板 1：评论                           │  │
│  │                                                          │  │
│  └──────────────────────────────────────────────────────────┘  │
└─────────────────────────────────────────────────────────────┘
```

### 固定顶栏（不滑动）

- **左侧：三个图标按钮**
  - 🏷 **标签**（默认激活） — 悬停切换到标签面板
  - 💬 **评论** — 悬停切换到评论面板
  - 👁 **浏览** — 纯显示总浏览次数，无交互
- **右侧：浏览过该产品的同事头像栈**
  - 仅显示有浏览记录的用户
  - 按浏览次数从高到低排列
  - 超过 N 个显示 `+N`（N 由容器宽度决定，约 5 个头像）
  - 悬停头像显示 tooltip：`"Conley · 12次"`

### 滑动内容区

两个面板（宽 200%），通过 CSS `transform: translateX()` 切换：

- **面板 0 — 标签**（默认显示）
  - 显示团队的简短关键词标签
  - 紧凑药丸样式，彩色背景/边框，白色文字
  - 每行 flex wrap 排列
  - 悬停标签显示 tooltip：`"Conley · 5/12"`（添加人 · 日期）
- **面板 1 — 评论**（悬停 💬 滑入）
  - 每条评论：头像 + 正文 + 日期
  - 正文最多显示 2 行，超出省略号截断
  - 不足 2 行则自然显示 1 行（标准 `-webkit-line-clamp: 2` 行为）
  - 悬停评论显示完整内容（`title` 属性）
  - 日期格式：今年 `"5/12"`，去年 `"25/5/12"`

## 交互行为

| 触发方式 | 行为 |
|---------|------|
| 鼠标停留在 box 区域 | 显示当前面板 |
| 鼠标离开 box 区域 | 自动回到标签面板（默认） |
| 悬停 🏷 图标 | 切换到标签面板 |
| 悬停 💬 图标 | 切换到评论面板 |
| 悬停 👁 图标 | 无交互，仅显示数字 |
| 悬停某一标签 | tooltip 显示添加人和日期 |
| 悬停某条评论 | tooltip 显示完整评论 |
| 悬停某用户头像 | tooltip 显示用户名和浏览次数 |

## 数据加载策略

- **搜索页（列表模式）**：仅在 box 首次渲染时加载汇总数据（stats + viewers 摘要）
- **悬停滑动切换面板**：切换到评论面板时才请求评论详情（按需加载）
- 避免首次渲染时加载大量数据导致卡顿

## 样式要点

- 标签：紧凑药丸样式，彩色背景白色文字，`border-radius: 2px`
- 评论：`-webkit-line-clamp: 2` 实现两行截断
- 头像：圆形裁剪，`border-radius: 50%`，尺寸约 20px
- 滑动动画：`cubic-bezier(0.4, 0, 0.2, 1)`，350ms 过渡
- 整体面板：120px 高度，浅灰背景 `#f5f6f8`
