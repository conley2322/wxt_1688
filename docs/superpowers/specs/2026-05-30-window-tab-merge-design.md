# 悬浮窗口 Tab 合并设计

## 背景

当前悬浮窗口有 3 个主 Tab（商品/供应商/分析），其中商品和供应商各自有 2 个子 Tab（评论/标签）。评论页面和标签页面的 UI、交互、代码结构几乎完全一样，存在明显的重复。

本设计将商品和供应商的评论与标签合并到各自的单页面中，消除子 Tab，标签以云的形式与评论共存。

---

## 1. 整体结构

### 1.1 Tab 结构变化

**旧结构：**
```
商品 Tab          供应商 Tab          分析 Tab
├── 评论           ├── 评论            ├── 用户浏览量
└── 标签           └── 标签            └── 浏览记录
```

**新结构：**
```
商品 Tab          供应商 Tab          分析 Tab
（一个页面）       （一个页面）          ├── 用户浏览量
                                       └── 浏览记录
```

### 1.2 页面布局（通用）

```
┌──────────────────────────────────┐
│ 标签云区域                        │ ← 顶部：标签云
├──────────────────────────────────┤
│ 评论列表（滚动区）                 │ ← 中间：评论列表
├──────────────────────────────────┤
│ 输入区                            │ ← 底部：输入框 + 模式切换
└──────────────────────────────────┘
```

### 1.3 供应商页面特殊项

供应商页面在标签云区域右侧多一个「已合作」勾选：

```
┌──────────────────────────────────┐
│ 🏷 标签云                  ✅ 已合作│
```

## 2. 标签系统

### 2.1 数据模型

```
Tag = {
  id: string,
  text: string,           // 标签文字
  font_color: string,     // 字体颜色
  bg_color: string,       // 背景颜色
  visibility: 'public' | 'private',  // 可见性
  creator: string,        // 创建者
  created_at: date,       // 创建时间
  like_count: number,     // 点赞/认同人数
}
```

### 2.2 标签云（顶部区域）

```
┌─────────────────────────────────────┐
│ 🏷 标签云                            │
│                                     │
│ [质量好 ×2] [包装一般 ×1]            │  ← 我的标签（排前面）
│                                     │
│ [快发货 ×5] [服务好 ×3] [样品快 ×1]   │  ← 其他人的标签（按点赞数降序）
│                                     │
│ [🔒 我的秘密 ×0]                     │  ← 私有标签（仅创建者可见）
└─────────────────────────────────────┘
```

**排序规则：**
- 第一组：我创建的标签（按点赞数降序）
- 第二组：其他人的公开标签（按点赞数降序）
- 私有标签：仅对创建者可见，排在「我的标签」组内

**标签样式：**
- `×N` = 点赞数（多少人认同这个观点）
- `🔒` = 私有标签标识
- 背景色 + 字体色由创建者设定

**鼠标悬停 Tooltip：**
```
┌──────────────────────────┐
│ 标签：质量好              │
│ 创建者：张三              │
│ 创建时间：2026-05-20      │
│ 认同人数：3人              │
└──────────────────────────┘
```
- 只显示数量，不展开具体人名列表

**点击操作：**
| 操作 | 行为 |
|------|------|
| 点击我创建的标签 | 取消（删除该标签） |
| 点击别人的公开标签 | 点赞（+1）/ 取消点赞（-1） |
| 点击私有标签 | 取消（删除） |

### 2.3 标签池（输入区标签模式下浮出）

```
┌──────────────────────────────────────┐
│ 可添加的标签：                        │
│ [好沟通] [价格合理] [样品快]          │  ← 未添加的标签，点击即添加
│                                      │
│ 已添加的标签（点击取消）：             │
│ [质量好 ×2] [快发货 ×5]              │  ← 已添加的标签，点击取消
└──────────────────────────────────────┘
```

- 已添加的标签不出现在「可添加」区域
- 标签池中的标签显示点赞数

### 2.4 创建新标签

在输入框输入新标签名后，下方展开配置：

```
┌──────────────────────────────────────┐
│ 🏷  新标签名                   [添加] │
├──────────────────────────────────────┤
│ 字体色: ●黑 ●白 ●红 ●蓝 ●绿          │
│ 背景色: ●绿 ●蓝 ●紫 ●橙 ●红 ●灰      │
│ 可见性: ○ 公开  ○ 仅自己可见          │
└──────────────────────────────────────┘
```

- 从标签池点击已有标签时不展开配置（直接添加）

## 3. 评论系统

保持现有功能不变：

| 功能 | 说明 |
|------|------|
| 排序 | 最新 / 最早 |
| 用户筛选 | 按用户过滤评论 |
| 点赞 | 每条评论可点赞 |
| 发评论 | 底部输入框发送 |

```
┌──────────────────────────────────┐
│ [用户筛选 ▾]              ⏱ 最新▼│ ← 工具栏
├──────────────────────────────────┤
│ 😊 张三 · 3天前                   │
│    这批货质量比上次好很多          │
│    👍 2                          │
├──────────────────────────────────┤
│ 😐 李四 · 1天前                   │
│    发货太慢了，催了三次           │
│    👍 0                          │
└──────────────────────────────────┘
```

## 4. 输入区

### 4.1 评论模式（默认）

```
┌──────────────────────────────────────┐
│ 😊  写点什么...                 [评论 ▾]│ [发送]
└──────────────────────────────────────┘
```

- 输入文字后点发送发评论
- 点击 `[评论 ▾]` 弹出模式切换菜单

### 4.2 标签模式

```
┌──────────────────────────────────────┐
│ 🏷  输入标签名...               [标签 ▾]│ [添加]
├──────────────────────────────────────┤
│ 快速添加：                            │
│ [好沟通] [价格合理] [样品快]          │ ← 标签池（已有标签，点击直接添加）
├──────────────────────────────────────┤
│ 字体色: ●黑 ●白 ●红 ●蓝 ●绿          │ ← 仅输入新标签名时展开
│ 背景色: ●绿 ●蓝 ●紫 ●橙 ●红 ●灰      │
│ 可见性: ○ 公开  ○ 仅自己可见          │
└──────────────────────────────────────┘
```

### 4.3 模式切换

```
点击 [评论 ▾] / [标签 ▾]
  └─→ 弹出下拉菜单
        ├── 评论（当前选中高亮）
        └── 标签
  └─→ 切换模式，placeholder 和按钮文字随之变化
```

## 5. 路由变化

### 旧路由
```
/product/comment
/product/tag
/supplier/comment
/supplier/tag
/analysis/views
/analysis/records
```

### 新路由
```
/product          ← 商品页（原 /product/comment）
/supplier         ← 供应商页（原 /supplier/comment）
/analysis/views
/analysis/records
```

移除 `/product/tag` 和 `/supplier/tag` 路由，标签功能合并到各自的主页面。
